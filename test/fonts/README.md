# Fonts used by visual tests

These font binaries are pinned test inputs copied from Flutter 3.47.0's
`bin/cache/artifacts/material_fonts` directory. Keeping them in the repository
prevents golden output from depending on host-installed fonts or a moving
Flutter SDK cache layout.

Roboto Regular, Medium, Bold, and Black cover the weights used by the UNUTMA
UI. Material Icons is pinned for deterministic icon glyphs. The accompanying
license files are the Apache 2.0 license texts distributed with Flutter.
